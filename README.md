# Tasa Barbershop — GitHub Pages Ready

Static front-end site for **Tasa Barbershop** structured for zero-config **GitHub Pages** hosting.

## Files
- `index.html` — Complete front-end site at repository root
- `images/` — Shop interior and gallery images
- `.nojekyll` — Disables Jekyll processing for direct static serving

## Deploy on GitHub Pages
1. Create a new GitHub repository and upload or push all files in this folder to the `main` branch.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose `main` and `/ (root)`, then click **Save**.
